
Vila Akoya wp-content starter
============================

Contents:
- themes/vila-akoya : custom theme starter
- plugins/vila-akoya-setup : optional admin notice helper

What this includes:
- Home, Village, Campsite, Booking, About, Contact, Campus, Forest School page templates
- Activation hook that creates the main pages and menu
- Built-in enquiry form that emails the WordPress admin email via wp_mail
- Placeholder visual assets derived from the supplied design screenshots

What this does not include yet:
- A full booking engine
- Advanced custom fields UI for every section
- SEO plugin configuration
- Production-ready media library population or brochure import

Recommended next steps after install:
1. Put this wp-content folder into a local WordPress install.
2. Activate the Vila Akoya theme.
3. Confirm the created pages in Pages.
4. Set admin email for form delivery.
5. Replace placeholder images and copy with real assets/content.
6. Add an SEO plugin if desired.
